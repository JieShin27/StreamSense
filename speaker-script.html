Here's the reality. A solo live seller has to be five people at once: host, customer service, cashier, stock-keeper, and marketer.

No human can do five things simultaneously for four hours. Something always breaks — and it's usually the sales. A seller mid-pitch can't stop to check if size M is in stock, so she guesses. Slide 6 ~45s

The StreamSense Solution — 11 Agents, 3 Phases

Our solution: 11 autonomous agents deployed across three phases.

Phase 1 — Before the Live: The Pre-Live Planning Team — Finance, Sales, and Compliance agents. They sync stock across all platforms, validate promotions, select top products based on data, and flag compliance risks before the live goes public.

Phase 2 — During the Live: The Live Backstage Team — Triage, Order & Stock, Price Guard, and Coach agents. They read every comment in real time, auto-reply to simple questions, escalate serious issues, atomically decrement stock across platforms, and flag price mismatches before they reach the buyer.

Phase 3 — After the Live: The Post-Live Wrap-up Team — Reconciliation, Restock, Follow-up, and Planner agents. They confirm every order, detect oversells, send follow-up messages, generate reports, and plan the next session.

Architecture note: StreamSense runs Pre-Live and Post-Live teams on WorkBuddy's multi-agent platform. The Live Backstage team runs on our own Supabase + DeepAgent runtime for sub-second response latency.

Slide 8 ~45s

How It Works — Comment to Action in 800ms

Every buyer comment enters a four-class triage pipeline.

Step 1: The Triage Agent classifies each comment using intent detection. Step 2: The Grounding Gate checks if an auto-reply can be grounded in the product database. If not — it's blocked and escalated.

Then four outcomes: Class A — Auto-Reply ("How much?" becomes "RM29.90, tap the yellow basket!" in under 500ms). Class B — Escalate ("Can I mix colors?" goes to the seller's prompt overlay). Class C — Warn (compliance-sensitive questions get flagged). Class D — Ignore (spam and emojis get filtered out).

After triage, the Order & Stock agent atomically decrements stock, the Price Guard verifies pricing, and the Coach Agent sends the seller real-time prompts like "Mention the new shade."

Key safety point: No agent is allowed to auto-reply unless its answer is grounded in the product database. This prevents hallucinated pricing and wrong stock claims — ever.

Slide 10 ~50s

Technical Architecture — Enterprise-Grade

StreamSense uses a decoupled architecture. The StreamSense App — built with Next.js, TypeScript, and Tailwind — is the host's real-time dashboard. It uses Supabase Realtime for sub-second sync of chat cards and atomic stock reservations with row-level locking.

The Live Backend runs on FastAPI and Node.js — high-performance webhook ingestion and deterministic rules engine. It receives chat payloads from TikTok Live and Shopee APIs in real time.

For AI, we use tiered compute: 70% of chat traffic is spam and noise — routed through cheap Small Language Models for instant classification. Only the 30% that are real product questions trigger expensive high-tier LLMs. This keeps unit economics positive even during viral streams with 500+ comments per minute.

The Grounding Gate is a deterministic code layer — not an LLM. It checks price_floors.json and stock counts before any reply goes out. No hallucinations, ever.

The two systems — WorkBuddy back office and StreamSense live app — integrate via simple JSON and CSV file handoff. No complex API coupling needed.
