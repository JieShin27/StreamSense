From comment to action — in 800ms.

Every buyer comment enters a four-class triage pipeline. The system decides what to auto-reply, what to escalate, and what to ignore.

STEP 3

STEP 4

→
STEP 5

Coach Agent

Sends seller real-time prompts: "Mention the new shade", "Show the back of the box".

SAFETY: GROUNDING GATE

No agent is allowed to auto-reply unless its answer is grounded in the product database. If the triage agent can't find a verified answer — the comment is escalated to the human seller instead. This prevents hallucinated pricing, wrong stock claims, and compliance violations. It is the single most important guardrail in the system.

Enterprise-grade live commerce, no agency team required.

StreamSense uses a decoupled architecture: WorkBuddy (Team Expert Mode) serves as the asynchronous back office for pre/post-live planning, while the StreamSense App serves as the real-time earpiece and dashboard. They communicate via secure shared file handoff (JSON/CSV).

AI Back Office WorkBuddy Team Expert Mode Agentic workflow for pre-live planning and post-live reconciliation. Fans out tasks to Finance, Sales, Compliance, Reconciliation, Restock, Follow-up, and Planner agents.

TIERED COMPUTE

70/30 LLM Routing

70% of chat traffic is spam, emojis, and noise ("🔥🔥🔥", "+1"). These are routed through cheap, low-latency Small Language Models (SLMs) for instant classification. Only the remaining 30% — genuine product questions, negotiation attempts, compliance-sensitive queries — triggers expensive high-tier LLMs.

Why this matters: During a viral stream with 500+ comments/minute, routing everything through GPT-class models would cost more than the stream earns. Tiered routing keeps unit economics positive.
GROUNDING GATE

Deterministic Hallucination Block

Before any auto-reply is sent, a deterministic code layer checks the Supabase database: does the product have stock? Does the suggested price violate price_floors.json boundaries calculated by StreamSense's Finance Agent?

If the AI suggests a discount below the floor, the Price Guard blocks it. If stock is zero, the reply is blocked. No hallucinated pricing, no wrong stock claims, no compliance violations — ever.

DATA FLOW — END TO END

Pre-Live Planning

Seller activates StreamSense Pre-Live mode. Finance Agent reads cost_sheet.csv and computes price floors. Compliance Agent scans for prohibited medical/legal claims, bounces back to Sales Agent for rewrites. Outputs price_floors.json + multilingual script.

Live Ingestion & Triage

FastAPI backend receives webhook POST payloads from TikTok Live / Shopee containing viewer IDs and comments. DeepAgent triage classifies each comment. Grounding Gate vetoes ungrounded replies. Supabase Realtime pushes results to the Next.js dashboard — host sees stock counter (120 → 117) and red [WARN HOST] cards.

Post-Live Reconciliation

App exports session.json with all reservations, chat logs, and blocked discounts. StreamSense's Post-Live team ingests it: Reconciliation Agent generates an Excel profit sheet. Follow-up Agent drafts Shopee Chat messages. Planner Agent saves next_live_faq.json for the next broadcast.

INTEGRATION STRATEGY

No complex API connection needed between the StreamSense back office and live app. The two systems integrate by passing JSON and CSV files through a single shared, authorized folder. WorkBuddy processes files as the back office; the StreamSense App handles the real-time chat interface. Full separation of concerns.

RISKS & MITIGATIONS
Platform API Changes

TikTok Live or Shopee could restrict third-party access to their comment or stock APIs.

Mitigation: DeepAgent uses official API channels only. Maintain a fallback mode that escalates all comments to manual when API access is disrupted.

Hallucination Risk

An LLM-powered auto-reply could hallucinate pricing or product information.

Mitigation: The grounding gate blocks every auto-reply that cannot be traced to the product database. Hallucinated answers never reach the buyer.

Multi-Language Errors

Malay, Chinese, and English mixed in the same comment stream could cause misclassification.

Mitigation: Triage uses a deterministic rule engine for classification, not LLM. Language detection runs as a separate pre-processing step before intent classification.

Seller Adoption

Solo sellers may be resistant to AI handling customer interactions.

Mitigation: Free tier lets sellers experience the value with zero risk. Auto-replies are always labeled as "assistant" — no deception. Escalation gives the seller full control over complex queries.
